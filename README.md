# Lumber Timeclock Implementation & Support

## Project Overview
Played a key role in implementing and supporting
Lumber, a workforce time-tracking application
used by an electrical construction company.

The platform allows employees to record their
working hours and identify which construction
projects they are clocking in from.

Worked alongside company leadership to introduce
the system, assist employees, and support
day-to-day operations.
